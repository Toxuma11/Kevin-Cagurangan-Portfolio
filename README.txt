KEVIN CAGURANGAN — FUTURISTIC DEVELOPER PORTFOLIO

HOW TO RUN
1. Extract this folder.
2. Open index.html in your browser.
3. For editing, open the folder in VS Code. You can use the Live Server extension for a local development server.

FILES
- index.html: page content and sections
- style.css: colors, layout, responsive design, animations
- script.js: mobile navigation, active section links, scroll reveal, and contact form

CUSTOMIZE BEFORE PUBLISHING
- Confirm the name, email address, and location.
- Replace the sample project concepts with real projects, descriptions, and repository/live-demo links.
- Update the skills to reflect tools you actually know.
- Add your real GitHub, LinkedIn, and other social links if desired.
- The contact form uses mailto and opens the visitor's email app; it does not send messages to a server.
- The sample portfolio projects are visual concepts, not actual deployed applications.

DEPLOY
You can publish the folder using GitHub Pages, Netlify, or Vercel as a static site. No build step is required.

PROFILE PHOTO
- The About section now includes a circular profile image.
- Replace profile-photo.svg with your own photo file (for example profile-photo.jpg), then update the image src in index.html to match.
- For a real photo, use a clear square headshot; the page crops it into a circle automatically.
